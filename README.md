# Impulso Studio

Landing page de una agencia ficticia, creada con HTML y CSS. No requiere instalación ni compilación. Abre `index.html` en el navegador para verla.

## Despliegue en Azure Static Web Apps

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En el portal de Azure crea un recurso Static Web App, selecciona el plan Free y el origen GitHub.
3. Autoriza GitHub, selecciona el repositorio y la rama. En los detalles de compilación usa Custom, `/` para la ubicación de la aplicación y deja vacías las ubicaciones de API y salida. Azure creará un flujo de GitHub Actions.
4. Espera a que termine la acción y abre la URL proporcionada por Azure.

El correo de contacto es ficticio y debe cambiarse antes de usar la página para un negocio.
